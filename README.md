# Sales-and-Profit Dashboards (Interactive Dashboard Creation using MS Excel)
## Project Objectives: The goal of this dashboard is to measure overall business performance by tracking sales, profit, and margins across products, regions, and time periods.

## Dataset Used
- <a href = "https://github.com/boddula1212/excel-dashboards/blob/main/Sales%20and%20Profit_Dashboard%20Data.xlsx">Dataset</a>

## Questions(KPIs)
•	What is the overall revenue generated? 
•	How much profit was earned after costs? 
•	What is the ratio of profit to sales? 
•	Which regions or product categories drive the most revenue? 
•	Which items are the best performers? 
•	Which customer groups contribute the most to sales? 
•	How are sales and profits trending over time? 
•	How do returns or discounts affect profitability?
